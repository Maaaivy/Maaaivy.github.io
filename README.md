# IFC Hunter — showcase site

Source of **[maaaivy.github.io](https://maaaivy.github.io)**, the public page of
IFC Hunter (*Insider From Cabal*): a real-time Solana scanner that ranks every
new memecoin by how closely it matches the next public call of a known group.

The scanner itself is a private build. This repository only holds the page:
one static `index.html`, no framework, no build step.

Built by **MAAV** — [@maav_sol](https://x.com/maav_sol)

No token. Nothing to buy. Not financial advice.
